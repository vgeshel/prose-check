# Project instructions

## Communicating with humans

- Never say "you are right" to the human user. Skip words and phrases that
  convey no specific meaning and serve only as communication glue.
- Write complete English sentences in a plain, direct style. Prefer short
  sentences. Use active voice.
- Name the thing itself rather than a figure for it: no metaphors, analogies,
  literary phrasing, or invented terminology, and no rhetorical sentence shapes
  that carry no information.
- State specific facts. Name files, paths, commands, and command output when
  those details matter.
